# PoruBot Agent

PoruBot Agent запускает локальных агентов в выбранной папке проекта. В приложении есть выбор модели и thinking level, профили «Код», «Данные» и «Вопрос», предпросмотр промпта, отчёт по токенам, таймер и форматирование ответов агента. Во время задачи верхняя строка показывает последний этап, полученный от CLI, и прошедшее время.

| Движок | Ключ | Исполняемый файл |
|---|---|---|
| Antigravity | Gemini API из AI Studio | `agy` |
| Claude Code | Anthropic API | `claude` |
| Codex | OpenAI API | `codex` |
| OpenRouter | OpenRouter API | `claude` |

Ключи, введённые в окно, по умолчанию хранятся в памяти приложения. По явному действию ключ можно сохранить в Связке ключей macOS или в хранилище текущего пользователя Windows с шифрованием DPAPI. При выборе движка и запуске задачи PoruBot Agent ищет установленный CLI. При отсутствии он скачивает официальный установщик этого CLI через HTTPS и запускает его. После успешной установки задача продолжится автоматически. Установка и запуск агента требуют доступа к сети. Модели и уровни reasoning зависят от ключа, установленного CLI и провайдера. Для OpenRouter предустановлены алиасы Claude. Пользовательский ID модели можно ввести вручную.

## Разговоры Codex и Antigravity

Выберите движок и рабочую папку. После первого успешного ответа PoruBot автоматически выбирает текущий разговор. Меню «Новый разговор» возвращает пустой контекст. Там же можно выбрать предыдущий разговор для этой папки или ввести UUID сессии из CLI. PoruBot хранит название и ID для списка, а историю загружает CLI.

## Генерация картинок

Выберите «Картинка», затем генератор Google (Nano Banana 2.1) или OpenAI (GPT Image 2.6 Flare). Укажите рабочую папку и введите описание. PoruBot вызывает API выбранного генератора с ключом этого провайдера. Картинка сохраняется в выбранной папке под новым именем. Генерация тарифицируется по тарифам выбранного провайдера. В macOS для ключа доступны кнопка «Сохранить ключ» и опция «Запоминать ключ». При следующем открытии PoruBot подставляет ключ из Связки ключей.

## Доступ агента

Настройки доступа сохраняются между запусками. В режиме «План» расширенные настройки не применяются. Доступ ко всем папкам добавляет файловые корни к рабочей области в рамках разрешений ОС. В Antigravity есть отдельные переключатели для всех команд и запуска команд без песочницы. Последний оставляет командам обычные разрешения пользователя на файлы и сеть.

## macOS

Нужна macOS 13 или новее. Для сборки установите Xcode Command Line Tools и выполните `bash macOS/build.sh`. Команда создаст приложение для архитектуры текущего Mac.

## Windows

Распакуйте архив и откройте **PoruBot Agent.exe**. Сборка для Windows 10/11 x64 включает среду .NET. Графический интерфейс запускается напрямую. Для автоматической установки агентских CLI используется системный `curl.exe` и официальный установщик выбранного провайдера. Требования к конкретному агенту определяет его поставщик. В режиме Claude Code и OpenRouter на Windows доступны операции с файлами, запуск команд из интерфейса отключён. Для локальных вычислений через команды на Windows выберите Antigravity или Codex.

Выбор темы находится в верхней строке окна. Доступны светлая, тёмная и системная темы. PoruBot запоминает выбор.

Для сборки из исходников используйте .NET 10 SDK: `dotnet publish Windows/Desktop/PoruBot.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true`.
